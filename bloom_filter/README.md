# 布隆算法

布隆算法通常指布隆过滤器（Bloom Filter），它是一种空间效率很高的概率型数据结构，用来快速判断一个元素“可能存在”或“一定不存在”于某个集合中。

## 核心特点

- 查询速度快，适合做大规模存在性判断
- 非常节省内存，相比直接存储完整集合更轻量
- 会出现误判：可能把“不存在”的元素判断为“可能存在”
- 不会漏判：如果判断为“不存在”，那就一定不存在
- 标准布隆过滤器通常不支持删除元素

## 工作原理

布隆过滤器内部维护一个位数组和多个哈希函数：

1. 添加元素时，使用多个哈希函数计算出多个位置
2. 把这些位置都标记为 `1`
3. 查询元素时，再计算同样的位置
4. 如果其中任何一个位置是 `0`，说明元素一定不存在
5. 如果所有位置都是 `1`，说明元素可能存在

## 常见用法

- 缓存系统中防止缓存穿透
- 数据库查询前做快速过滤，减少无效查询
- 爬虫系统中判断 URL 是否访问过
- 黑名单、白名单的快速预筛选
- 推荐系统和日志系统中的去重预检查

## 优缺点

优点：

- 占用空间小
- 插入和查询效率高
- 很适合海量数据场景

缺点：

- 有误判概率
- 标准实现删除不方便
- 无法直接拿到真实元素内容，只能判断存在性
