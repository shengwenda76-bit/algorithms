# 按位版布隆过滤器 Design

**目标**

在 `bloom_filter` 目录下新增一个真正按位存储的布隆过滤器示例文件，不修改现有 `bloom_filter.py`，并为新文件补充中文注释与可直接运行的自测代码。

**设计**

- 新文件路径为 `bloom_filter/bit_bloom_filter.py`
- 使用一个整数 `bits` 保存全部位状态，通过位运算读写具体位置
- 对外接口保持简单，提供 `add()`、`contains()` 与 `__contains__()`
- 关键位运算步骤使用中文注释解释，便于学习
- 文件底部保留 `assert` 自测，直接运行即可验证

**测试策略**

- 先写依赖 `BitBloomFilter` 的自测并运行，确认因类未定义而失败
- 再补最小实现并重新运行，确认自测通过
